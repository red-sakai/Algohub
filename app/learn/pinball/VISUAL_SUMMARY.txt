═══════════════════════════════════════════════════════════════════════════

WHY PINBALL?
┌─────────────────────────────────────────────────────────────────────────┐
│  ✓ Sequential      Ball visits one node at a time (like algorithm)     │
│  ✓ Deterministic   Rail paths ensure correct order (no chaos)          │
│  ✓ Engaging        Arcade aesthetic maintains attention                 │
│  ✓ Memorable       Visual associations aid retention                    │
└─────────────────────────────────────────────────────────────────────────┘

COLOR CODING:
  🔴 Red (Preorder)    → Aggressive, top-down cascade
  🟢 Green (Inorder)   → Systematic, sorted sweep
  🔵 Blue (Postorder)  → Building up to root

MOTION STYLES:
  🔴 Cascade → Falls like dominoes (parent first)
  🟢 Zigzag  → Sweeps horizontally (sorted order)
  🔵 Climb   → Ascends to root (children first)
